# Offline Desktop Data Manager – Python + Eel

تطبيق سطح مكتب يعمل بالكامل **بدون إنترنت**، تم تطويره باستخدام **Python** مع واجهة أمامية مبنية بـ **HTML, CSS, JavaScript**.  
التطبيق مصمم خصيصًا للعمل على **الأجهزة القديمة**، ويتميز بسهولة الاستخدام وإمكانية إدارة وتخزين البيانات بشكل محلي دون أي اتصال خارجي.

---

## 📌 مميزات التطبيق
- يعمل **100% أوفلاين** بدون أي قواعد بيانات خارجية أو سيرفر.
- حفظ البيانات في ملف محلي عبر Python في ملف JSON للحفاظ عليها بعد إغلاق البرنامج.
- واجهة مستخدم بسيطة وسهلة مناسبة لأي مستخدم.
- **إضافة / تعديل / حذف** البيانات داخل جدول ديناميكي.
- قائمة **Right Click** تحتوي على:  
  - تعديل  
  - حذف
- **بحث فوري (Live Search)** داخل الجدول.
- التحقق من **التكرار** لمنع إدخال نفس البيانات أكثر من مرة.
- ميزة **الطباعة** مع إمكانية تحديد تاريخ معيّن للطباعة.
- تحميل البيانات تلقائيًا عند فتح التطبيق.
- متوافق مع الأنظمة القديمة وأجهزة الإمكانيات المحدودة.

---

## 🛠️ التقنيات المستخدمة
- **Python 3**
- **Eel** (لربط الواجهة الأمامية مع الباك-إند)
- **HTML / CSS / JavaScript**
- Local JSON Storage
